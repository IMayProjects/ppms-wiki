# User Management

The User Management module allows System Administrators to provision, configure, and maintain user accounts across the department.

## Account Administration

System Administrators manage access credentials and operational profiles for all system users:

1. **User Provisioning**: Create new user accounts linked to official `@ecdoe.gov.za` email addresses.
2. **Role Assignment**: Assign one or more functional roles (Data Capturer, Programme Manager, Corporate Planning, Senior Management, Auditor, or System Administrator) in accordance with the user's institutional responsibilities.
3. **Programme Allocation**: Map Data Capturers and Programme Managers to their respective departmental programmes and outcome indicators.
4. **Access Governance**: Deactivate accounts, reset credentials, and audit user login sessions to ensure compliance with departmental security standards.
