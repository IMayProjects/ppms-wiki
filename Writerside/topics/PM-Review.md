# Programme Manager Review

As outlined in [Understanding Your Role](Understanding-Your-Role.md), the Programme Review dashboard is the primary landing page for a Programme Manager upon login.

![Programme Review Dashboard](../images/pm-review-landing.png)

## Navigate Between Programmes

From the left navigation panel, select the desired programme from the list under `My Programmes`.

![Navigation Panel | Programme Manager](../images/pm-review-nav.png){width="320"}

## View Indicator Submissions

The main interface displays indicator reports categorized across reporting statuses.

![Pending Indicators List | Programme Manager](pm-review-list-pending.png)

In the table titled `All Captures`, you can monitor submissions according to their current workflow status: **Not Submitted**, **Pending**, **Approved**, or **Rejected**.

To evaluate an individual submission, see [Review an Indicator](Indicator-Review.md). Once all indicators for a programme have been approved, see [Submit a Programme Overview](Programme-Overview.md).
