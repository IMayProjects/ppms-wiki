# Administrator Manual

Welcome to the Programme Performance Monitoring System (PPMS) Administrator Manual. This manual provides comprehensive operational guidance for System Administrators responsible for system maintenance, user governance, and reporting configuration within the Eastern Cape Department of Education.

## Overview

The administrator module enables authorized administrators to manage core application configurations and enforce institutional access controls.

Key administrative responsibilities include:

- **[System Administration](System-Administration.md)**: Overseeing global parameters, environment settings, and institutional reporting policies.
- **[User Management](User-Management.md)**: Provisioning user accounts, configuring authentication credentials, and assigning role-based access permissions.
- **[Programmes & Indicators](Programmes-Indicators.md)**: Configuring departmental programmes, performance indicators, and Technical Indicator Descriptions (TIDs).
- **[Reporting Periods](Reporting-Periods.md)**: Setting up financial years, quarterly reporting windows, and submission deadlines.
