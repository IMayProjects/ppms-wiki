# Review an Indicator

This section describes the procedure for evaluating indicator submissions within the Programme Review module.

![](pm-review-actions.png)

To initiate the review of an indicator submission, click the **View** icon ![](fa-eye-512.png){width="24"} in the `Actions` column.

![pm-review-popup.png](pm-review-popup.png)

A review window displays the captured quarterly submission data, the Technical Indicator Description (TID), and the uploaded Portfolio of Evidence (POE).

After verifying the reported values and evidence against the technical indicator specifications, select one of the following options:

- Click [Accept](0:0){as="button" nullable="true"} to approve the submission.
- Click [Reject](0:0){as="button" mode="classic" nullable="true"} to reject the submission.

If the submission is rejected, you will be prompted to provide a formal justification, and the report is returned to the Data Capturer for correction. For details on rejection handling, see [Review &amp; Rejections](Rejections.md).
