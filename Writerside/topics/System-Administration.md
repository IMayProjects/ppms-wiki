# System Administration

The System Administration module provides tools for configuring institutional parameters, maintaining system health, and governing user access across the Programme Performance Monitoring System (PPMS).

## Administrative Functions

System Administrators are responsible for the following key governance areas:

- **[User Management](User-Management.md)**: Administer user accounts, manage contact information, and assign operational roles across branches and districts.
- **[Programmes & Indicators](Programmes-Indicators.md)**: Define and structure departmental programmes, sub-programmes, performance indicators, and technical measurement parameters.
- **[Reporting Periods](Reporting-Periods.md)**: Configure reporting cycles, activate annual planning windows, and enforce quarterly submission deadlines.
